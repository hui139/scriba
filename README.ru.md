# Scriba

**Открытый Markdown-редактор с WYSIWYG и поддержкой плагинов**

Синтаксис Markdown скрыт за набранным результатом: только строка под курсором показывает исходный текст, всё остальное отображается так, как будет выглядеть в готовом документе.

## Возможности

**Работа с текстом**

- Заголовки, полужирный, курсив, зачёркивание, выделение, подчёркивание, верхний и нижний индексы, встроенный код, ссылки, изображения, цитаты, списки, списки задач, разделители, сноски, `[TOC]` и YAML-метаданные отображаются сразу при вводе
- Таблицы редактируются напрямую: добавление строк и столбцов, выравнивание через контекстное меню, изменение ширины перетаскиванием (двойной щелчок возвращает автоширину)
- Скриншоты и файлы изображений можно вставлять и перетаскивать: они сохраняются в `assets/` и подставляются ссылкой, с указанием размера `=200x`
- Enter продолжает список, Backspace удаляет маркер, выделенный текст превращается в ссылку при вставке URL
- Поиск по всему рабочему пространству, панель структуры, вкладки, недавние файлы, режим исходного кода
- Поиск и замена с учётом регистра, по целым словам, с регулярными выражениями и заменой всех вхождений
- Режим сосредоточения и режим пишущей машинки

**Вёрстка и экспорт**

- Формулы KaTeX (в строке `$...$`, блоком `$$...$$`) и диаграммы Mermaid отображаются в реальном времени
- Экспорт в HTML, PDF, Word, обычный текст, PNG, LaTeX и EPUB (многоуровневое оглавление по заголовкам)
- Относительные пути к изображениям встраиваются при экспорте; в EPUB изображения упаковываются в архив
- Экспорт папки: Markdown и изображения копируются вместе
- Шаблоны оформления экспорта: достаточно положить CSS в `<userData>/export-templates/`

**Настройка**

- Шесть встроенных тем (по умолчанию Violet Night, на основе цветов иконки приложения), поддержка собственного CSS и тем плагинов
- Масштаб интерфейса от 85 % до 140 %, размер текста документа настраивается отдельно
- Любое сочетание клавиш можно переназначить; при конфликте прежняя привязка снимается автоматически
- Языки интерфейса: английский и упрощённый китайский, плагины могут добавлять свои

**Расширяемость**

- Плагины на JavaScript регистрируют команды, сочетания клавиш, элементы строки состояния, панели боковой панели, обработчики блоков кода, темы и языки
- Магазин плагинов ищет их по теме GitHub `scriba-plugin`, центральный индекс не нужен

## Сборка из исходного кода

Требуются **Node.js 20+** и npm 10+.

```bash
git clone https://github.com/hui139/scriba.git
cd scriba
npm ci
npm run dev
```

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Режим разработки с горячей перезагрузкой |
| `npm run build` | Сборка в `out/` |
| `npm run typecheck` | Проверка типов TypeScript |
| `npm test` | Все тесты (модульные и UI-тесты) |
| `npm run test:compat` | Модульные тесты: совместимость версий и локализация манифеста |
| `npm run smoke` | UI-тест на реальном приложении |
| `npm run dist` | Сборка установщика для текущей платформы в `release/` |
| `npm run icons` | Пересборка всех иконок из исходного изображения |

## Плагины

Плагин размещается в `<userData>/plugins/<id плагина>/` и содержит `manifest.json` и точку входа CommonJS, экспортирующую `activate(scriba)`:

```js
module.exports.activate = (scriba) => {
  scriba.commands.register({
    id: 'my-plugin.hello',
    name: 'Say Hello',
    run: () => scriba.ui.showToast('Hello from my plugin!')
  })
}
```

Полное описание API — в [docs/PLUGIN_API.md](docs/PLUGIN_API.md). Включать, отключать и устанавливать плагины из папки можно в **менеджере плагинов** внутри приложения.

Плагины можно распространять: публичный репозиторий с темой `scriba-plugin` появится в магазине плагинов приложения. Требования — в [docs/PLUGIN_SPEC.md](docs/PLUGIN_SPEC.md).

## Структура проекта

```
src/
  main/             Главный процесс Electron (окна, файловая система, плагины, экспорт, проверка обновлений)
  preload/          API contextBridge
  renderer/         Рендерер на React
    src/editor/     Редактор CodeMirror и живой предпросмотр
    src/plugins/    Среда выполнения плагинов и реестр точек расширения
    src/components/ Компоненты интерфейса
    src/markdown/   Преобразование Markdown в HTML для экспорта
plugins/            Встроенные плагины (время чтения, языковая метка блоков кода)
scripts/            Запуск, сборка иконок, тесты
docs/               Документация
```

## Безопасность

Плагины — это обычный JavaScript в рендерере с теми же правами, что и у редактора. **Устанавливайте только те плагины, которым доверяете.** Включена изоляция контекста, политика безопасности содержимого не содержит `unsafe-eval`; точки входа плагинов загружаются как Blob-модули и требуют только `script-src blob:`.

Сейчас плагины не подписываются и не изолируются — это известное ограничение, описанное в [docs/PLUGIN_SPEC.md](docs/PLUGIN_SPEC.md#九已知限制).
